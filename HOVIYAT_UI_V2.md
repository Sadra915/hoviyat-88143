# Hoviyat UI v2

This update introduces a communication-first visual layer without changing the existing JavaScript/Supabase contracts.

## Main changes
- Reduced glassmorphism and decorative cards.
- Cleaner mobile-first chat list.
- More compact filter chips.
- Redesigned chat header, bubbles and composer.
- Native-feeling bottom navigation.
- Mobile-first bottom-sheet modals.
- Cleaner settings and identity surfaces.
- Dedicated dark-mode surfaces.
- Better desktop centering and spacing.
- Accessibility focus states and reduced-motion support.

## Compatibility
The redesign is loaded after `css/style.css`, so the existing application logic remains untouched.
