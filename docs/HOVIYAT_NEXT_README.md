# HOVIYAT NEXT

این نسخه یک لایه‌ی توسعه‌ای روی هسته‌ی موجود هویت است، نه بازنویسی پیام‌رسان.

## مهم
- فایل‌های موجود auth/chat/groups/channels/call/voice حفظ شده‌اند.
- `css/hoviyat-next.css` لایه‌ی ظاهر را اضافه می‌کند.
- `js/hoviyat-next.js` تنظیمات ظاهری، پس‌زمینه، glass، motion، power saving و UX را مدیریت می‌کند.
- `js/media-editor.js` ویرایش عکس قبل از ارسال را در مرورگر انجام می‌دهد.
- هیچ کلید service_role یا secret در کلاینت قرار نگرفته است.

## SQL
فایل‌های `supabase/next/006...011` افزایشی هستند. فایل 008 و 010 عمداً gate شده‌اند تا قبل از private کردن storage، لینک‌های رسانه‌ی قدیمی نشکنند.

## امنیت
هسته‌ی امنیت موجود شامل RLS، محدودسازی نرخ، TOTP، نشست‌ها، قفل برنامه، WebAuthn/biometric و رمزگذاری در حالت سکون است. این نسخه audit trail و rate helper افزوده و private-storage migration را بدون تست اجباری نکرده است.

## منابع طراحی و امنیت
الگوهای UX از پیام‌رسان‌های مدرن مطالعه شده‌اند، اما کد یا asset اختصاصی سرویس‌های دیگر کپی نشده است. چک‌لیست امنیتی بر اساس اصول OWASP ASVS و مستندات رسمی Supabase تنظیم شده است.
